# Публикация через ngrok

Для показа приложения снаружи запустите локально Compose и убедитесь, что frontend доступен по адресу `http://localhost:8080`.

1. Создайте аккаунт на [ngrok.com](https://ngrok.com/) и скопируйте authtoken из панели управления.
2. Установите официальный `ngrok` для своей ОС и сохраните токен локально командой `ngrok config add-authtoken <ВАШ_ТОКЕН>`. Токен хранится в конфигурации ngrok, не добавляйте её в Git.
3. Запустите туннель на HTTP-порт frontend: `ngrok http 8080`.
4. Откройте HTTPS-адрес `Forwarding`, который напечатает ngrok. Проверьте загрузку главной страницы, затем создание события и доступность `https://<адрес-туннеля>/api/events`.
5. Остановите туннель сочетанием `Ctrl+C` в окне ngrok.

В MVP нет авторизации, поэтому любой пользователь с адресом туннеля может создавать, изменять и удалять события. Используйте временный туннель только для демонстрации и выключайте его сразу после показа. Не публикуйте Grafana, Prometheus или PostgreSQL через этот туннель.
